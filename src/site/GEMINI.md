# Storefront Context & Rules

When modifying or adding storefront code (`src/site/`):

1. Consult [`docs/FRONTEND.md`](file:///D:/freelance/vazo-website/docs/FRONTEND.md) for UX layouts, mega-menu structures, and editorial rhythm.
2. Consult [`docs/ECOMMERCE.md`](file:///D:/freelance/vazo-website/docs/ECOMMERCE.md) for product models and retail/wholesale purchasing rules.
3. Consult [`docs/DESIGN_SYSTEM.md`](file:///D:/freelance/vazo-website/docs/DESIGN_SYSTEM.md) for semantic color tokens and typography hierarchy.
4. Keep the storefront modular and responsive across mobile, tablet, and desktop breakpoints.
5. Do not import admin components into storefront modules.
